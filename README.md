# Data_Engineering

Данный репозиторий предназначен для выполнения заданий по дисциплине "Инжиниринг данных"

[Датасет на Google Drive](https://drive.google.com/drive/folders/1WtNE7mtGj4gSK8cTiUReBqz30Pr-MNCD)

**Размер файла** `Oil_Pipeline_Accidents.csv` **≈ 908 КБ**

**Содержание:** по каждому инциденту дата и время, оператор и трубопровод, причина аварии, тип разлитой жидкости и объем потерь, число пострадавших и погибших, связанные затраты

## Домашнее задание №2 и №3 — загрузчик и приведение типов датасета

Скрипт `data_loader.py` скачивает датасет с Google Drive через `gdown` и читает его с помощью `pandas`. При первом запуске файл сохраняется в папку `data/`, при следующих используется локальная копия. Скрипт выводит в консоль первые 10 строк таблицы и ее размер.

Требуется Python 3.9+.

### Развертывание окружения

```bash
# 1. Создайте виртуальное окружение в папке проекта
python3 -m venv .venv

# 2. Активируйте его
source .venv/bin/activate      # macOS / Linux
.venv\Scripts\activate         # Windows

# 3. Установите зависимости
pip install -r requirements.txt
```

### Запуск

```bash
python data_loader.py
```

При первом запуске датасет (~908 КБ) скачивается с Google Drive в папку `data/`, затем скрипт печатает первые 10 строк таблицы. Ожидаемый вывод:

```
Размер датасета: 2795 строк, 48 столбцов
```

## Домашнее задание №5 — EDA

Разведочный анализ датасета лежит в ноутбуке [`notebooks/EDA.ipynb`](notebooks/EDA.ipynb): структура и схема данных, пропуски и их природа, уникальность, бизнес-правила, выбросы, корреляции, метрики качества данных и выводы для ETL.

Ноутбук сохранен вместе с результатами, поэтому его можно читать прямо на GitHub без запуска. Зависимости для ноутбука лежат отдельно в `notebooks/requirements.txt`. Чтобы перезапустить ячейки, установите их и выберите ядро `.venv`:

```bash
source .venv/bin/activate
pip install -r notebooks/requirements.txt
```

Датасет ноутбук берет из `data/`, а если его там нет — скачивает через `data_loader.py`.

## Домашнее задание №6 — визуализация на seaborn

В тот же ноутбук [`notebooks/EDA.ipynb`](notebooks/EDA.ipynb) добавлена визуализация на `seaborn`:

- все графики из ДЗ №5, которые строились через `pandas.plot` и `matplotlib`, перестроены на seaborn;
- добавлен раздел «7. Расширенная визуализация»: карта пропусков по записям, тепловая карта аварий «год × месяц», нарушения бизнес-правил по годам, время остановки трубопровода относительно аварии, распределения затрат по причинам и типам продукта, округление объемов утечки, своевременность подачи отчетов.

Графики помогли найти новые проблемы качества данных: границы смены формы отчета (2013 и 2015 годы), провал в декабре 2015 года, копирование времени аварии в поле остановки, округление малых утечек до галлонов. Они добавлены в выводы и рекомендации для ETL.

Все графики статичные (PNG) и сохранены в ноутбуке, поэтому отображаются на GitHub. Новых зависимостей не нужно — `seaborn` уже есть в `notebooks/requirements.txt`.

## Структура репозитория

- `data_loader.py` — скачивание датасета и вывод первых строк
- `notebooks/EDA.ipynb` — ДЗ №5 и №6, разведочный анализ данных и визуализация
- `data/` — локальная копия датасета, создается скриптом при первом запуске (в git не коммитится)
- `requirements.txt` — зависимости
- `.gitignore` — не пускает в git датасет и виртуальное окружение
