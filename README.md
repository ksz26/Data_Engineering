# Data_Engineering

Данный репозиторий предназначен для выполнения заданий по дисциплине "Инжиниринг данных"

[Датасет на Google Drive](https://drive.google.com/drive/folders/1WtNE7mtGj4gSK8cTiUReBqz30Pr-MNCD)

**Размер файла** `Oil_Pipeline_Accidents.csv` **≈ 908 КБ**

**Содержание:** по каждому инциденту дата и время, оператор и трубопровод, причина аварии, тип разлитой жидкости и объем потерь, число пострадавших и погибших, связанные затраты

## Домашнее задание №2 — загрузчик датасета

Скрипт `data_loader.py` скачивает датасет с Google Drive через `gdown` и читает его с помощью `pandas`. При первом запуске файл сохраняется в папку `data/`, при следующих используется локальная копия. Скрипт выводит в консоль первые 10 строк таблицы и её размер.

Требуется Python 3.9+.

### Развёртывание окружения

```bash
# 1. Создайте виртуальное окружение в папке проекта
python3 -m venv .venv

# 2. Активируйте его
source .venv/bin/activate      # macOS / Linux
.venv\Scripts\activate         # Windows

# 3. Установите зависимости
pip install -r requirements.txt
```

### Запуск

```bash
python data_loader.py
```

При первом запуске датасет (~908 КБ) скачивается с Google Drive в папку `data/`, затем скрипт печатает первые 10 строк таблицы. Ожидаемый вывод:

```
Размер датасета: 2795 строк, 48 столбцов
```

## Структура репозитория

- `data_loader.py` — скачивание датасета и вывод первых строк
- `data/` — локальная копия датасета, создаётся скриптом при первом запуске (в git не коммитится)
- `requirements.txt` — зависимости
- `.gitignore` — не пускает в git датасет и виртуальное окружение
